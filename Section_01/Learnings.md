# Lecture 02 - 
* What is backend and Client-Server Architecture?    
    1) What is a server (backend)?
       A server or backend is a computer or system which sends, or we can call it, "serves" the data, resources to the clients with the help of network.
       It accepts the requests from the clients, processes them, and sends the appropriate data or resources to the clients which they are looking for.

    2) What is the Client?
       Client is a computer or software which requests for data, resources to the server with the help of the network.
       They basically interact with servers by sending requests and accepting responses from the servers, through software applications or web servers. 

# Lecture 03 - 
* CLI vs GUI
   1) What is CLI?
      CLI stands for Command Line Interface. It's a text- and black-screen-based interface where we can type commands and perform tasks. We can interact with the system by typing text commands and terminal consoles.
   
   2) What is GUI?
      GUI stands for Graphical User Interface. It's a visual interface where users can interact with the system using buttons, drag-and-drop elements, menus, etc. Users can perform tasks and coding operations using buttons, Drag-and-drop features and mouse.
