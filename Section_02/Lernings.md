# Lecture 02 - 
* echo, pwd and whoami commands
 1) echo: prints the exact values of data such as strings, variables etc.
 2) pwd: prints the current directory path which we are currently using.
 3) whoami: prints the Desktops name mentioned in our system settings.

# Lecture 03, Lecture 04, Lecture 05 - 
* basic bash commands - cd, ls, cp, mv, rm, rmdir, rm -r. 
 1) cd - navigate to a folder/directory
 2) ls - list all files & folders in a directory
 3) cp - copy a folder or file 
 4) rm - remove a file 
 5) rmdir - remove an empty folder 
 6) rm -r - remove a non-empty folder 

# Lecture 06 - 
* files reading and editing with cat, nano and vim commands - 
1) cat (concatenate): reads/prints a file in terminal in chunks and concatenate them as a full text representation
2) nano : a terminal based text editor where we can edit the file as text 
3) vim : similar to nano editor with some advance features and functionalities

# Lecture 07 -
