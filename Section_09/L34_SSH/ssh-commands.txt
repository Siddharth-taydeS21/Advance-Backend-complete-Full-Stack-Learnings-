// ======== copy file from client to server or server to client using scp command ======== //

1. syntax when the destination-machine ip address is an IPv4 address - 
scp "source-path/" <destination-machine username>@<destination-machine ip address>:<destination path for pasting the file>

2. syntax when the destination-machine ip address is an IPv6 address - 
scp <destination machine-username>@[destination machine IPv6 address]:destination machine path for pasting the file

3. copy the file form server to client
spc <server machine username>@<server machine ip address>:<file path in server machine> <client machine path for pasting the file>



// ========= assignment : try to copy a folder from client to server then server to client using scp command ========= //
Done -- we can copy the directory form source to destination using this command and '-r' recursive flag - 
scp -r "path of directory" <>@<>:<path to paste the directory>


// ======== auth less client-server communication using private and public keys in shh ======== //

step 1 - generate cryptographic private and public keys - 
ssh-keygen 

step 2 - paste the public key in server machine's .shh/authorized_keys file

// ======== ssh connection with -i flag (identify ssh public key file) ======== //
ssh -i "ssh public key file path" <machine-name>@<machine-ip-address>
